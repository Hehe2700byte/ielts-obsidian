# 雅思备考 · Obsidian 仓库

Academic 机考备考记录，包含每日打卡、教练反馈、模板、日期提醒与复习计划。

## 使用

1. 克隆或下载此仓库。
2. 在 Obsidian 选择“打开本地仓库”，选择该目录。
3. 打开 `首页.md`；通过日记功能或 `⌘⇧D` 打开当天打卡。

日记保存于 `每日打卡/YYYY-MM-DD/打卡.md`。截图、录音等附件随笔记存档。

## 版本管理

保留笔记、学习附件及通用 Obsidian 设置；忽略设备工作区、缓存、废纸篓和 macOS 杂项文件。

GitHub 上的备份仅包含已提交并推送的内容。Obsidian 保存笔记不会自动推送，也不会自动触发教练批改。

本仓库包含个人学习记录，建议保持私有。
